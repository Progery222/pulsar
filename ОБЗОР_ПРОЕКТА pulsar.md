# Pulsar (Beatleap Atom) — обзор проекта

**Версия:** 1.5.0 · **Платформа:** Windows · **Стек:** Electron 34 + React 18 + TypeScript + Vite + Zustand + Tailwind; встроенные FFmpeg/FFprobe (ffmpeg-static), exiftool-vendored, опциональный Python для нейро-функций (librosa, Whisper, Edge TTS, deep-translator, yt-dlp).

## О чём проект

Десктопный «комбайн» для производства и массовой подготовки коротких видео под соцсети (TikTok / Reels / Shorts / YouTube). В одном окне: автомонтаж под ритм музыки, уникализация видео/изображений/метаданных, очистка чужих титров, озвучка и дубляж, транскрибация, скачивание, запись экрана и AI-генерация роликов. Максимум работы — офлайн, локально, с GPU-ускорением где возможно.

Стартовый экран (**ModeSelector**) — 14 модулей в трёх категориях + сквозные **Очередь задач**, **История**, **Настройки** и **Мастер первого запуска** (ставит Python и движки).

## Модули

### Категория «Видео»
| Модуль | Что делает |
|---|---|
| **Монтаж** | Автосборка клипа в ритм музыки. Два режима: **Быстрый** (beat-sync: 1–30 видео + трек из библиотеки 20+ треков или свой MP3/WAV → анализ битов librosa → нарезка по mood mellow/natural/energetic → 9 эффектов ×3 уровня, 10 фильтров, fade, формат 9:16/1:1/16:9 → экспорт с пресетами TikTok/Reels/Shorts/YouTube/Instagram, 720p–4K, опционально N уникальных копий) и **Студия** (WebGPU-редактор на базе OpenReel: таймлайн, цветокор, эффекты, маски, ключи, экспорт до 4K). Есть также Pro-таймлайн (`src/pro`) с Auto-Cut. |
| **Запись экрана** | Захват экрана/окна в высоком качестве с авто-зумом к курсору (собственная реализация). |
| **Сплит-монтаж** | Хук сверху + эмоция снизу, эффекты по ячейкам, генерация N уникальных вариаций. |
| **AI-ролик по теме** | Тема → сценарий → сток-видео → озвучка → субтитры → готовый ролик. |
| **Шаблоны (AI)** | Фото → вырезка фона → дизайн-шаблон с анимацией и текстом. |
| **Скачать видео** | Пакетная загрузка по ссылкам (TikTok, YouTube, Instagram и сотни площадок) через yt-dlp с автоустановкой; сохранение в `Загрузки/Beatleap/`. |

### Категория «Уникализация»
| Модуль | Что делает |
|---|---|
| **Уникализатор (VUB)** | Каждое видео × N вариаций со случайными, но контролируемыми трансформациями: яркость/контраст/резкость/громкость/темп/поворот, шум, цветосдвиг, кроп, сдвиг аудио, зеркало и т.д. 9 вкладок настроек, многопоточность, GPU. |
| **Замена титров (AI)** | Детект чужих титров/водяных знаков/плашек (Python `detect_overlays.py`), автоперекрытие, наложение своих субтитров. |
| **Удаление фона** | ИИ-вырезание фона у изображений (`@imgly/background-removal`), кисть-доводка, экспорт PNG. |
| **Изображения** | Пакетное сжатие, ресайз, конвертация форматов, кроп, фильтры — локально. |
| **Метаданные** | Полный просмотр EXIF/GPS/C2PA + вердикт «ИИ / реал». Редактор любого поля, рандом-заполнение (телефон/гео/дата), пакетная обработка, полная очистка; фото и видео (MP4/MOV — правка, MKV/WEBM/AVI — чтение). |

### Категория «Озвучка»
| Модуль | Что делает |
|---|---|
| **Субтитры / Транскрибация** | Офлайн-распознавание речи (Whisper) → SRT / TXT / VTT. |
| **Озвучка (TTS)** | Синтез речи из текста (Edge TTS, много языков/голосов) и наложение на видео. |
| **Дубляж (AI)** | ASR → перевод → TTS → синхронизация по таймингам → выжигание субтитров. |

### Скрытый/служебный
| Модуль | Что делает |
|---|---|
| **Воронка (Funnel)** | Ссылка → скачивание → AI-классификация (Gemini) → автообработка по одной из 5 веток (уникализация / удаление сабов + дубляж / дубляж / замена плашки / комбинация) → результат. |

## Инфраструктура

- **Архитектура:** Renderer (React/Zustand) ↔ IPC ↔ Main (Electron/Node: FFmpeg, файлы, spawn) ↔ Python-скрипты (`beat_detect.py`, `tts.py`, `translate.py`, `detect_overlays.py`, `whisper_asr.py`, `upscale.py`), отдающие JSON.
- **Без Python** работают монтаж (fallback на равномерную нарезку), уникализатор, изображения, метаданные, запись экрана.
- **Первый запуск:** мастер ставит Python (winget) и движки Edge TTS / deep-translator / yt-dlp / Whisper с живым логом.
- **Хранение:** `settings.json` (GPU-режим, папки, язык), `history.json` (до 200 записей), `vub-secrets.json` (API-ключи, шифрование DPAPI).
- **Обновления:** electron-updater, публикация релизов на GitHub (`Progery222/pulsar`).
- **Скрипты:** `npm run dev` / `build` / `release` / `typecheck` / `studio:build` (сборка вендоренной Студии через pnpm).
