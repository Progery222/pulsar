## 0. Резюме в шести строках

1. Из 14 заявленных модулей **12 проходят сценарий до файла-результата**, но только 4 из них работают «из коробки» без Python и без чужих ключей: Уникализатор, Изображения, Метаданные, Запись экрана (ядро). Остальные упираются в pip-установки на 0.1–5 ГБ и/или ключи AssemblyAI / OpenRouter / Pexels.
2. **Два модуля — призраки.** «Pulsar Pro» (`src/pro`, 4 639 строк, 83 коммита) отключён от стартового экрана с 7 июля и недостижим из UI; «Воронка» (`src/funnel` + `electron/ipc/funnel.ts`, 943 строки) снята с главной 10 июля, попасть в неё нельзя. Это примерно четверть кода приложения, которую никто не видит.
3. **Витрина флагмана — подделка.** Встроенная библиотека «20 треков по 3 минуты» — это 20 сгенерированных ffmpeg болванок по 20,04 с каждая (`ffprobe`: `duration=20.035918`, `encoder=Lavf60.16.100`), при этом `src/data/tracks.json` обещает 165–192 с и вымышленных артистов. Первый же ролик в Быстром монтаже сделан под фальшивый трек.
4. **Приложение бесплатное и не имеет никакой оплаты, лицензии, триала, телеметрии, EULA и подписи кода.** Репозиторий `Progery222/pulsar` публичный, без файла LICENSE. Это внутренний инструмент «для друзей» (`release.ps1`: «друзья получат обновление»), а не продукт.
5. **Фокус потерян.** 448 коммитов за 10 недель: 250 в июле (14 модулей за 3 недели), 42 в августе, 8 в сентябре. За август развивался ровно один модуль — Метаданные (29 коммитов по путям), который уже вынесен в отдельный SaaS «Метка». Остальные 13 модулей с конца июля в заморозке де-факто.
6. Главный юридический риск — не yt-dlp, а **`@imgly/background-removal` под AGPL-3.0**, вшитый в бандл рендерера (Удаление фона + Шаблоны). Продавать закрытый Pulsar с ним нельзя без коммерческой лицензии IMG.LY или открытия исходников под AGPL.

### 2.4 Абзац-вердикт

Pulsar — не продукт, а **портфолио из 14 демо**, собранных одним человеком за 4 недели под лозунг «заменить связку сервисов». Глубина есть у трёх (VUB, Метаданные, Быстрый монтаж), у остальных — рабочий счастливый путь и ноль полировки. Стартовый экран показывает 14 равноправных карточек и ничем не подсказывает, что 4 из них требуют 5 ГБ загрузок, а 3 — платных ключей на чужих сайтах. Для инди-продукта на аудиторию заливщиков разумный периметр — 5–6 карточек: Скачать → Уникализатор → Сплит → Замена титров → Метаданные (+ Быстрый монтаж как витрина, когда у него появится настоящая музыка). Всё, что требует PyTorch, — в раздел «Лаборатория» с явным предупреждением; всё, что требует OpenRouter, — убрать до появления серверной прослойки с собственным ключом.

### 3.2 Шаги до первого результата

**Самый простой модуль без Python — «Изображения»** (`src/imgopt/ImgOptApp.tsx`): карточка → «+ Добавить» (диалог) → ползунок качества → «Сохранить все» → выбор папки → готово. **5 кликов, 0 загрузок, < 1 минуты.** Аналогично «Метаданные»: карточка → перетащить файл → мгновенная таблица EXIF → «Случайно» → «Сохранить». Оба модуля — для ЦА вспомогательные.

**Уникализатор (профильный, без Python)**: карточка → вкладка «Загруженные видео» → добавить (диалог/DnD) → пролистать левое меню из 11 пунктов до последнего «Производительность» → выбрать папку (или «рядом с исходником») → «Запустить». **~7 кликов через два конца длинного меню; вариаций по умолчанию 1** — новичок получит один перекодированный файл и не поймёт, где «массовая уникализация». Ни на одной вкладке нет кнопки запуска, кроме последней.

**Быстрый монтаж (флагман, без Python)**: «Начать» → выбор видео → «Далее» → выбор трека → обработка → редактор → Ctrl+S / «Экспорт» → папка. ~8 кликов, 2–3 минуты. Но: трек из библиотеки — 20-секундная болванка с подписью «2:58»; биты — равномерная сетка с тостом «Python не найден»; осциллограмма — формула. **Первый результат флагмана — ролик под шум длиной 20 с.**

**Дубляж (максимальный путь)**: Python через winget + UAC + перезапуск → Whisper (pip + 460 МБ) → deep-translator → OmniVoice (5.5 ГБ; на 50 Мбит/с ~15–20 мин чистой загрузки) или остаться на Edge → карточка «Дубляж» → видео → папка → «Запустить» → Whisper small на CPU (минута на минуту речи) → Google Translate → синтез (на CPU OmniVoice — минуты на фразу, `tts.py` снижает до 16 шагов) → склейка. **~15 действий, перезапуск приложения, до 6 ГБ трафика, 30–60 минут до первого файла; сквозной прогон этого пути из UI автором не сделан** (`PROGRESS_TTS.md` 3.8). Точки отказа: winget, UAC, PyPI/pytorch.org, HF-зеркало, Google-капча, CUDA OOM при < 4 ГБ VRAM, Edge TTS заблокирован Microsoft.

### 3.3 Где новичок сдастся (по убыванию вероятности)

1. **SmartScreen на неподписанном инсталляторе** — до запуска.
2. **Мастер первого запуска**: экран закрыт модалкой с требованием Python; «Пропустить» — серая кнопка справа внизу. Часть уйдёт, часть нажмёт «Скачать Python» и упрётся в UAC/winget/перезапуск.

4. **14 одинаковых карточек**: нет входа «начни отсюда», нет демо-проекта, нет примерных файлов.

6. **Быстрый монтаж**: фальшивая музыка убивает доверие у тех, кто дошёл.

## 4. Монетизация и дистрибуция

### 4.1 Что есть в коде и документах

Ничего. `grep -rni "licen|лиценз|оплат|trial|подписк|активац|stripe|yookassa"` по `src/`, `electron/`, `*.md` — ноль совпадений (кроме FONTS_LICENSES.txt). Нет EULA, нет экрана «О программе», нет телеметрии/аналитики/крэш-репортов (`posthog|sentry|analytics` — ноль), кнопка обратной связи в проде не сконфигурирована (§1.2). Нет README и файла LICENSE в корне при **публичном** репозитории (`github.com/Progery222/pulsar`, 10 релизов видны) — формально «все права защищены», фактически исходники открыты, любой может собрать.

`ОТЧЁТ_ПО_ПРОЕКТУ_Pulsar.md` называет продукт «внутренний инструмент автоматизации подготовки видеоконтента», автор — «начальник сектора автоматизации»; `release.ps1` — «друзья получат обновление». То есть **бесплатность — не стратегия, а отсутствие решения**: продукт делался как рабочий инструмент для своей команды и знакомых.

### 4.2 Что это означает

- Нет обратной связи: ни телеметрии, ни работающего фидбэка, ни канала — все «UX-находки» получены только чтением кода.
- Нет обязательств и нет бюджета на поддержку: 6 ГБ зависимостей на машинах пользователей будут ломаться (yt-dlp, edge-tts, torch), а чинить это бесплатно некому.
- Публичный репозиторий без лицензии + AGPL-зависимость + «обход антидублей» в документации — комбинация, при которой любой конкурент может забрать код, а платёжный провайдер — отказать.

### 4.3 Подпись кода и SmartScreen

- Подписи нет: `package.json.build.win` без `certificateFile`/`signtoolOptions`, в `release.yml` — только `npm run release`.
- Следствие: SmartScreen «Неизвестный издатель» на каждом релизе; репутация файла копится неделями и сбрасывается на каждый новый exe. При 7 релизах за 2 дня предупреждение будет всегда.
- `electron-updater` без подписи на Windows работает (проверка издателя пропускается), но пользователь всё равно видит предупреждение при первом инсталляторе.
- Варианты: OV-сертификат code signing (~$200–400/год, нужна компания; из РФ — через европейских реселлеров, напр. Certum с верификацией личности для ИП/физлица); Azure Trusted Signing недоступен без 3-летней истории организации; для open-source — SignPath Foundation бесплатно, но требует открытой лицензии. Либо реже релизить и предупреждать в README о SmartScreen.

1. **Один аккаунт и один ключ** — лицензия Pulsar = подписка «Метки» уровня Про и выше (десктоп как бонус к вебу, а не отдельная касса). У ЦА потребление рваное, и «Залив» на 7 дней с полным Pulsar — честный аналог $12.99/7д у 360U.
2. **Pulsar как воронка в «Метку»**: карточка «Метаданные» в Pulsar остаётся бесплатной для одиночных файлов, пакет > N файлов и API — через «Метку». Обратно: в «Метке» кнопка «Нужно видео и уникализация → скачайте Pulsar».
3. **Бэкенд «Метки» как прокси** для AssemblyAI/LLM под подписку — снимает «принеси свой ключ» из VUB-титров, AI-глав и AI-ролика.
4. Один движок метаданных (`electron/ipc/metadata.ts` ↔ порт в «Метке», см. `metka-engine-fixes`) — фиксы должны идти в обе стороны, иначе через месяц это два разных продукта.

### 6.2 Репутационные и продуктовые

- «AI» в названиях трёх карточек там, где AI нет или он чужой по ключу (Шаблоны, Замена титров — OpenCV/EAST, Дубляж — Google Translate).
- Фальшивая музыкальная библиотека — единственный «контент» внутри продукта оказывается шумом.
- Неподписанный инсталлятор + 7 релизов за два дня + нерабочая кнопка обратной связи = образ нестабильной самоделки.
- `pip install --upgrade torch` в системный Python ломает чужие AI-инструменты пользователя — сразу негатив от самой технической части аудитории.
- 02a: ошибки pip/ffmpeg по-английски, тосты без «Подробнее» (часть починена 2.09).

### 6.3 Технические, влияющие на продукт

- Автообновление без подписи по HTTPS с GitHub — приемлемо, но любая компрометация аккаунта `Progery222` = раздача чего угодно всем пользователям.
- Студия собирается только вручную и коммитится бандлом — регрессии в OpenReel будут накапливаться незаметно.
- Мёртвые Pro и Воронка (6 000+ строк) продолжают компилироваться и тянут общие типы — каждое изменение `src/vub/types.ts`, `tts.ts`, `dub.ts` проверяется ещё и на них.
