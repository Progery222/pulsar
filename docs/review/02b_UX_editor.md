## 2. Обратная связь при долгих операциях

9. **К** `beatDetection.ts:71-74,31-42` — **молчаливый фолбэк**: при отсутствии Python/librosa `catch {}` → `fallbackBeatData` = нарезка каждые 0.5 с. Пользователь получает ролик НЕ в ритм, экран пишет «Анализируем аудио…» → «Готово!», главный экран обещает «Создавай видео в ритм музыки». Он не узнает никогда. → Как в Pro (`ProEditor.tsx:60`): тост «Ритм не определён — равномерная сетка 0.5 с» + «Установить анализ ритма».
10. **В** `ProcessingScreen.tsx:36-57` — прогресс декоративный (10 → 40 → 70 → 100 по номеру шага); самый долгий этап стоит на 10 % — визуально зависание. → Тикающий прогресс + «Анализ ритма, до 30 секунд…».
11. **В** `ProcessingScreen.tsx:71-75` — `run().catch(console.error)` → переход в редактор с «Нет клипов» без объяснения. → Тост с причиной + «Повторить».
12. **К** `ExportModal.tsx:85-92` — `window.alert('Ошибка при обработке видео… Детали: ' + stderr FFmpeg)`: системный alert в тёмной теме, без прокрутки и копирования. → Свой диалог: причина, свёрнутые «Технические подробности», «Скопировать отчёт».
13. **В** `ExportModal.tsx:67,84` — отмена экспорта записывается в очередь как ошибка (`status: 'error'`), «тихо, без уведомления». → Статус `cancelled` + тост «Экспорт отменён».
14. **В** `EditorScreen.tsx:616-620` — стадии по порогу процента (<85 «Рендеринг», <95 «Применяем уникализацию», иначе «Финализация»); при N копий (`ffmpegBuilder.ts:89` делит прогресс) надписи врут; «копия 7 из 50» не показано. → «Готово 7 из 50 · осталось ≈ 12 мин».
15. **В** `UniqualizerPanel.tsx:17` — `COUNTS = [1,2,3,10,20,40,50,100]`: 100 копий 4K одним кликом без оценки времени и места. → «100 копий ≈ 2 ч 40 мин, ≈ 18 ГБ», подтверждение при >20.
16. **В** `ExportModal.tsx:56` vs `:76` — реальные имена `pulsar_${Date.now()}.mp4`, в историю пишутся выдуманные `pulsar_1.mp4…`. → Возвращать фактические пути.
17. **Ж** `ExportModal.tsx:79-82` — результат экспорта 50 файлов — тост на 3 с. → Постоянная карточка результата: путь, число файлов, «Открыть папку».
